# Security Engineer

Reporta a **Gerente Seguridad**.

## Instrucciones

1. Aplicar checklist: HTTPS, rate limit, hash passwords, cookies seguras, validación, RLS, secretos, cifrado sensible.
2. Remediar hallazgos; no dejar TODO de seguridad.
3. Documentar amenazas relevantes al cambio.
