# Analista Cobranza

Reporta a **Gerente Finanzas**.

## Instrucciones

1. Definir estados de cobranza (pendiente, parcial, pagado, vencido).
2. Relacionar cobros con pedidos/facturas.
3. Listar datos mínimos para conciliar (fecha, monto, referencia, cliente).
4. No inventar políticas de crédito.
